# 🔧 Development Guide

## Prerequisites

| Tool | Version | Install |
|---|---|---|
| Python | 3.11+ | [python.org](https://python.org) or `pyenv install 3.11` |
| Docker Desktop | Latest | [docker.com](https://docker.com) |
| Git | 2.x | `brew install git` |
| `gh` CLI | Optional | `brew install gh` |

---

## Initial Setup

```bash
# 1. Clone
git clone https://github.com/jellyfishing2346/fraud-detection-engine..git
cd fraud-detection-engine.

# 2. Configure environment
cp .env.example .env

# 3. Start infrastructure
cd infra
docker compose up -d
docker compose ps   # wait for (healthy)

# 4. Install Python dependencies
cd ../backend
python3.12 -m pip install -r requirements.txt

# 5. Install dev tools
pip install pre-commit ruff
pre-commit install   # hooks run on every commit

# 6. Train the model (requires Kaggle dataset)
python3.12 ml/train.py --data notebooks/creditcard.csv

# 7. Seed test data
python3.12 scripts/seed.py

# 8. Start the API
export DATABASE_URL="postgresql://fraud_user:fraud_pass@127.0.0.1:5432/fraud_db"
python3.12 -m uvicorn main:app --reload
```

## Environment Variables

All config lives in `.env`. Copy from `.env.example` to get started.

| Variable | Default | Description |
|---|---|---|
| `DATABASE_URL` | `postgresql://fraud_user:...` | PostgreSQL connection string |
| `REDIS_URL` | `redis://localhost:6379` | Redis connection |
| `KAFKA_BOOTSTRAP_SERVERS` | `localhost:9092` | Kafka broker |
| `KAFKA_TOPIC_RAW` | `transactions.raw` | Raw transaction topic |
| `KAFKA_TOPIC_SCORED` | `transactions.scored` | Scored output topic |
| `MODEL_PATH` | `models/xgb_fraud_v1.joblib` | Trained model path |
| `FRAUD_SCORE_THRESHOLD` | `0.4` | Score cutoff for flagging |
| `APP_ENV` | `development` | Environment name |

## Linting

[Ruff](https://docs.astral.sh/ruff/) runs automatically on every commit via pre-commit hooks.

```bash
# Run manually
cd backend
ruff check .        # lint
ruff format .       # format

# Run on specific file
ruff check api/routes/score.py

# Auto-fix all fixable issues
ruff check . --fix
```

### Ruff rules enforced
- `E` — pycodestyle errors
- `W` — pycodestyle warnings
- `F` — pyflakes (unused imports, undefined names)
- `I` — isort (import ordering)
- `B` — flake8-bugbear (common bugs)
- `UP` — pyupgrade (modern Python syntax)

## Git Workflow

### Branch naming
```
week{N}/{description}    e.g. week3/scoring-api
chore/{description}      e.g. chore/linting-setup
hotfix/{description}     e.g. hotfix/latency-bug
```

### Commit messages (Conventional Commits)
```
feat: add velocity feature using Redis sorted set
fix: correct offset commit order in consumer
chore: update dependencies
docs: add API reference
test: add pytest cases for score endpoint
```

### Daily workflow
```bash
# Start of session
git pull origin main
git checkout your-branch

# Work and commit often
git add -p                  # review changes interactively
git commit -m "feat: ..."

# End of session — always push
git push origin your-branch
```

### PR process
1. Push branch to GitHub
2. Open PR with descriptive title + body
3. Add `Closes #N` to link the issue
4. Merge (branch protection requires PR — no direct pushes to main)

## Useful Commands

```bash
# Connect to Postgres directly
docker exec -it fraud_postgres psql -U fraud_user -d fraud_db

# Check Redis
docker exec -it fraud_redis redis-cli

# List Kafka topics
docker exec -it fraud_kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 --list

# Watch Kafka topic in real time
docker exec -it fraud_kafka /opt/kafka/bin/kafka-console-consumer.sh \
  --bootstrap-server localhost:9092 \
  --topic transactions.raw \
  --from-beginning

# Reset consumer group (replay all messages)
docker exec -it fraud_kafka /opt/kafka/bin/kafka-consumer-groups.sh \
  --bootstrap-server localhost:9092 \
  --group fraud-scorer \
  --topic transactions.raw \
  --reset-offsets \
  --to-earliest \
  --execute
```

## Adding a New Endpoint

1. Add route function to `backend/api/routes/score.py` or `alerts.py`
2. Run `ruff check . --fix && ruff format .`
3. Add a pytest test in `tests/test_score.py`
4. Run `python3.12 -m pytest tests/ -v` — all tests must pass
5. Commit and open PR

## Troubleshooting

### `role "fraud_user" does not exist`
The app is connecting to a local Postgres instead of Docker. Fix:
```bash
export DATABASE_URL="postgresql://fraud_user:fraud_pass@127.0.0.1:5432/fraud_db"
```

### `ModuleNotFoundError: No module named 'imblearn'`
You're running with the wrong Python. Use `python3.12` explicitly:
```bash
python3.12 -m pip install imbalanced-learn
python3.12 -m uvicorn main:app --reload
```

### Kafka consumer not receiving messages
Check Kafka is running and the topic exists:
```bash
cd infra && docker compose ps   # kafka should be Up
docker exec -it fraud_kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 --list
```

### Dashboard shows "Could not connect to API"
The dashboard must be served via the API (not opened as a file):
```bash
# Wrong — opens as file://
open frontend/dashboard.html

# Correct — served via FastAPI
open http://localhost:8000/dashboard
```
